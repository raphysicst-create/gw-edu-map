# 강원 교육지도 원자료 요청 초안 — 미발송

이 문서는 외부 기관에 보내지 않은 **검토용 초안**이다. 개인이 만드는 업무 참고용 ‘강원 교육지도’이며 교육청 공식 서비스가 아니다. 학생·교직원의 개인별 자료는 요청하지 않는다. 자료의 공개 경로를 우선 확인하고, 제공 불가 또는 비공개 항목은 요구하지 않는다.

## 강원특별자치도교육청에 보낼 수 있는 문안

안녕하세요. 강원 18개 시군의 초·중·고·특수학교 교육 현황을 공식 공개 자료만으로 비교하는 비공식 교육지도를 개발하고 있습니다. [학교개황](https://www.data.go.kr/data/15106701/fileData.do) 2026-04-01 CSV는 확보했으나 학교 식별자, 본교·분교, 운영상태와 좌표가 없어서 학교 수와 위치를 정확히 공개하기 어렵습니다. 아래 자료의 기존 공개 위치 또는 제공 가능 여부를 안내받고 싶습니다.

1. 학교별 **공식 학교 ID**와 코드체계, 학교명, 학교급, 설립구분, 본교·분교 구분, 운영·휴교·폐교 상태, 소재 시군, 도로명/지번 주소를 같은 기준일로 연결할 수 있는 학교 일람표. 식별자가 변경·통합되었다면 변경 전후 대응 및 적용일도 부탁드립니다.
2. 학교개황의 모집단·제외 기준과 정확한 기준일. 학교개황과 대조할 때 **취득한 2026 일람표에서 중학교 1교와 고등학교 7교를 찾지 못했습니다**. 해당 학교명·공식 ID, 운영상태, 본분교 여부, 수록 범위를 확인할 수 있는 공식 목록 또는 설명을 부탁드립니다. 이 잠정 수치를 교육청의 공식 누락 통계로 단정하지 않습니다.
3. 학교별 공식 위치 좌표가 있다면 학교 ID와 함께 좌표값, 원좌표계(EPSG 코드 또는 좌표계 설명), 위치 기준(정문·대표 건물·필지 중심 등), 측량·갱신 기준일을 부탁드립니다. 좌표 원본과 이를 변환한 지도 점을 **정적 파일에 영구 저장하고 공개 웹앱에서 재배포**할 수 있는지, 허용 범위·출처표시·변경 가능 여부를 자료별로 명시해 주시면 감사하겠습니다. 저장이나 재배포가 허용되지 않으면 해당 조건도 알려 주십시오.
4. 2023~2026년 제공 가능한 학교별 학생·학급·교원·입학생, 교지면적, 교실 유형, 일반학교 특수학급·학생, 사서교사·상담교사 수. 교육부 직접 제공 2022 학교별 파일은 확보했습니다. 연도별 정확한 기준일, 학교급·운영상태·본분교 포함 범위, `0`·결측·비공개·해당 없음의 구분, 교원 범주를 함께 부탁드립니다.
5. 위 학교별 자료와 **동일한 기준일·학교급·모집단 정의**의 시군별 및 도 전체 공식 집계표. 학교 개별행을 합한 값과 공표 합계가 다르면 이유를 알 수 있는 주석이 있으면 도움이 됩니다.
6. 전체 폐교재산과 현재 활용상태·폐교일 목록. [미활용폐교현황](https://www.data.go.kr/data/15106700/fileData.do)은 전체 폐교 명단이 아니므로 전체 수의 분모로 사용하지 않겠습니다. 이 자료의 공공누리 제3유형 조건 아래 시군별 집계, 지도 표시, JSON 변환, 원문 링크와 출처표시를 동반한 가공 결과 공개가 가능한지 자료 제공기관의 명시적 해석을 부탁드립니다.
7. [2026 강원교육 주요업무계획](https://www.gwe.go.kr/main/content.do?key=bTIzMDcyMTEyMTA5NTQ%3D)의 PDF와 [2026 강원특수교육 운영계획](https://www.gwe.go.kr/main/bbs/view.do?bbsSn=48548&key=bTIzMDkxMTk1OTM5Mjc%3D)의 HWP에 적용되는 자료별 공공누리 유형 또는 이용조건을 안내 부탁드립니다. 정책명·관련 쪽수·정책 취지를 짧게 정리해 원문 링크와 함께 비공식 웹앱에 표시하고, 근거 원문을 내부 보관하는 용도입니다. 정책 연도와 학교 통계의 조사연도는 구분하며 계획을 집행 실적이나 효과로 표현하지 않겠습니다. 전체 원문을 웹앱에서 재배포할 계획은 없습니다. 요약·출처표시·내부 저장 각각의 허용 범위와 게시일을 확인하고자 합니다.

가능한 경우 CSV 또는 XLSX의 원본 공개 경로를 안내 부탁드립니다. 각 자료의 제공기관, 정확한 기준일과 게시일, 라이선스 표시, 저장·가공·재배포 조건을 함께 확인하고자 합니다. 비공개 소수값은 보존하며 역산하지 않겠습니다.

## 이미 확보한 공간자료와 별도 확인 사항

국가데이터처의 [2025-06-30 SGIS 시군·행정동 경계](https://www.data.go.kr/data/15129688/fileData.do)와 국토교통부의 [2026-06-30 법정동 코드](https://www.data.go.kr/data/15063424/fileData.do)는 이미 공개 파일로 확보했다. 따라서 동일 경계를 다시 신청하지 않는다. 코드체계·기준일·좌표계·해시는 [`GANGWON_SPATIAL_SOURCES.md`](GANGWON_SPATIAL_SOURCES.md)에 기록한다.

국토지리정보원의 국가관심지점정보(POI)는 공식 학교 좌표 후보이나 로그인 다운로드가 필요하고 학교 ID 결합 여부가 확인되지 않았다. VWorld API의 지오코딩 결과는 저장·재배포 승인 근거가 없으므로 학교 좌표 원본으로 삼지 않는다. 이 초안으로 회원가입·유료 신청·문의 발송은 수행하지 않았다.
