# 2020·2021 교육부 직접 제공 학교별 통계 조사

조사일: 2026-09-26. 범위는 교육부 누리집의 유력 게시물 4건과 2020년 연보 검색 1건으로 제한했다. 기준은 [2022년 교육부 교육기본통계 자료 게시물](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=351&boardSeq=92557&lev=0&m=0310)처럼 교육부가 **특정 학교별 XLSX를 직접 첨부**하고, 학교 공식 코드·본분교·상태·조사 기준일·게시물 이용허락을 확인할 수 있는지다. KESS에 동명 자료가 있다는 사실만으로 교육부 직접 제공 원본으로 등록하지 않는다.

위 네 게시물의 HTML과 검색 결과 HTML은 무시되는 `data/raw/gangwon/research-history/`에 조사 증거로 보관했다. **2020·2021 학교별 통계 파일은 취득하지 않았으므로** `history-sources.json`에는 원본 해시·취득일·`publishable` 상태를 만들어 등록하지 않았다. 2022 공식 원본은 기존 [`moe-sources.json`](../data/sources/gangwon/moe-sources.json)에 독립적으로 기록되어 있다. 현재 확인된 교육부 직접 제공 자료만으로 2020/2021↔2022의 학교별 다년 추이를 만들 수 없다.

후속 확보가 가능해지면 연도별 원본의 실제 학교코드 체계, 상태·본분교 및 학교수 세는 방법, 정확한 항목별 기준일, 강원 18시군 포함 범위, 숫자 열 의미, 공공누리 표시를 2022 원본과 각각 대조해야 한다. KESS 기관 파일은 특정 교육부 직접 첨부라는 별도 근거가 확인되기 전에는 이 출처 등록부에 승격하지 않는다.
