# 강원 개정 실행 기록

갱신: 2026-09-26. 기준 커밋: `c7d03f5`. 구현과 검사는 별도 담당자가 수행합니다.

## 현재 상태

**2022년 통계 제한 공개(limited), 전체 개정 미완료.** 교육부 직접 첨부 학교별 XLSX와 국가데이터처 정부 경계·국토교통부 코드를 연결했습니다. 2022-04-01 기준 대상 본교 634교(초349·중161·고115·특수9)가 별도 강원교육통계연보와 일치하며, 분교를 포함한 학교별 통계를 제공합니다. 2026년 현황으로 표시하지 않습니다.

`public/data`에는 제한 공개 manifest와 동일 버전의 50개 파일(학교·경계·지표·학교별 보조 통계·가공 보고서)이 있습니다. 662 원시 행에서 폐교 5행(본교3·분교2)을 제외한 학교 657개를 제공합니다. 학교 좌표는 657개 전부 null이며 시군 지도와 검색·상세로 제공합니다. 기존 전북 공개 파일은 Git 제외 경로 `data/interim/gangwon/previous-releases/<실행ID>`에 백업한 뒤 공개 폴더에서 제외했습니다. 전북 파일을 강원 복구본으로 사용하지 않습니다. 운영 배포는 하지 않았습니다.

## 구현 내용

- **지역:** 강원 18개 시군, 도 전체 내부 코드 51000. SGIS 통계지역코드 32/32010 등과 법정동 계열 내부 코드 51/51110 등을 명시적 대응표로 분리했습니다.
- **출처:** 기본·학교 상세·공간 자료 등록부를 통합해 읽습니다. 허용 기관·공식 도메인·원본 해시·이용조건·심사 상태를 확인하며 자동으로 공개 승격하지 않습니다. 초기 CSV의 잘못된 학교급·인용부호를 거부합니다.
- **학교:** 일람표 어댑터가 학교별 총계와 특수학교 전체과정을 분리합니다. 공식 코드가 없으면 원문 시트/행을 내부 레코드 위치로 기록합니다. 학교명에 분교장 표기가 없는 경우 본교로 단정하지 않습니다.
- **교육부 원본:** 교육부가 직접 게시한 2022 학교별 XLSX를 별도 어댑터로 연결했습니다. 공식 KEDI·나이스 코드, 본분교·운영상태와 2022-04-01 기준일을 사용하며 2026 자료와 결합하지 않습니다. 별도 검사자의 원문·코드·합계·라이선스 심사를 거쳐 공개 원천으로 승격했습니다.
- **집계:** 강원 전용 순수 집계 모듈을 공개 파이프라인에 연결했습니다. 모집단·본교 여부·숫자가 미확인인 경우 null과 사유를 유지하고, 비율은 총합/총합으로 계산합니다. 폐교 제외·휴교 포함이며 학교수와 소규모 기준은 본교에만 적용합니다.
- **경계:** 국가데이터처 공식 ZIP의 SHP/DBF/PRJ/CPG를 사용하고 EPSG:5179에서 WGS84로 변환합니다. ZIP 해시 확인 후 임시 폴더에 추출합니다. 예전 개인 GitHub 경계 CLI는 강원에서 실행을 차단했습니다.
- **공개 계약:** manifest 및 파일의 profile/schema/dataVersion을 검사합니다. 공개 가능 출처와 파일 체크섬·목록을 확인하고 staging을 검증한 뒤 공개 폴더를 교체합니다. 실패한 교체는 기존 폴더를 복구합니다. 전체 출력 내용·정의·출처에서 버전을 산정하며 생성시각은 제외합니다. 공개용 `provenance.json`에 원문 해시·모집단·제외·결측을 기록합니다.
- **수동 복구:** 이전 강원 공개본을 검증하는 미리보기와 현재 버전 확인을 포함한 복구 명령을 추가했습니다. 선택한 백업과 교체 직전 공개본을 보존하며 빌드와 잠금을 공유합니다. 별도 검사자가 임시 작업공간에서 복구 9건과 기존 공개 잠금 회귀 5건, 총 14건을 통과했습니다. 실제 운영 호스팅·코드 버전의 복구는 별도 미검증입니다.
- **화면:** 18개 지표·10개 주제의 미제공 사유, 준비 상태, 다른 지역/버전 거부, 가용 파일만 로드, 버전별 행정동 캐시와 오류 재시도를 연결했습니다. 강원 시야·설정 저장 키·개인 도구 브랜딩·공유 이미지를 반영했습니다.
- **시계열:** 비교하는 두 관측연도가 연속되지 않으면 ‘전년’ 대신 실제 비교연도를 표시합니다. 예를 들어 2022·2026 자료만 있는 경우 ‘2022년 대비’로 안내하며, 이전 값이 null이면 증감을 표시하지 않습니다.
- **외부 지도:** VWorld의 저장·캐시 조건 검토가 끝나지 않아 배경지도·건물 API를 비활성화했습니다. 키만 입력해도 활성화되지 않습니다. 건물 응답은 no-store이며 외부 호출 전에 차단합니다.

## 10개 교육문제

학교 규모 차이, 지역소멸과 작은학교, 특수교육, 폐교 활용, 기초학력, 독서, 돌봄, 마음건강, 진로, AI 교육을 모두 등록했습니다. 정책 원문과 해당 주제의 완전한 통계·기관 명단을 연결하기 전에는 주제별 사유를 표시합니다. 자료 없는 주제를 삭제하거나 정책 효과를 추정하지 않습니다.

2026 주요업무계획의 원문과 쪽수는 [정책 조사 기록](GANGWON_POLICY_SOURCES.md)에 보관했습니다. 원문 취득과 공개 심사는 별개이며, 현재 10개 주제 모두 미제공 상태입니다. 학교별 입학생·특수학급·사서·상담교사 수 파일의 제공은 이 정책 주제 전체의 공개를 뜻하지 않습니다.

## 검사 및 다음 단계

계획서 11~16절의 요구사항별 완료 범위와 남은 조건은 [인수 감사](GANGWON_ACCEPTANCE_AUDIT.md)에 기록했습니다. 현 제한판의 검사 통과와 전체 개정·운영 인수를 구분합니다.

독립 결과는 [검증 기록](GANGWON_VERIFICATION.md)을 기준으로 합니다. 실제 경계·코드·학교 원본·공식 합계·공개 계약과 제한 공개 산출물 검증을 통과했습니다. 최종 데이터 재생성·검증, 타입 검사와 프로덕션 빌드가 통과했고, lint 오류 0·기존 경고 1입니다.

전체 Playwright 범위는 최종 코드 기준 묶음별 실행과 실패 항목 재검사를 중복 없이 합산해 89개 중 82개 통과·기존 외부 조건에 따른 skip 7개·미실행 0입니다. 실제 API가 필요한 2개와 배포 주소가 필요한 5개는 로컬 검증에 포함하지 않았습니다. 실제 2022 제한 공개판과 합성 준비 화면 15개를 최종 프로덕션 서버에서 재검사해 모두 통과했습니다. 좌표 있는 학교의 점·HUD 동작은 합성 자료로 확인했고, 실제 공개 자료에서는 공식 좌표 미확보 상태를 확인했습니다. 마지막 전체 단일 명령을 다시 실행한 결과로 표현하지 않습니다.

일반 Vitest에서 원본 파일 의존을 제거하고 시계열 비교연도 회귀를 추가한 전체 실행(수동 복구 명령 추가 전)은 888개 중 881개 통과·실패 0·명시적 원본 검사 skip 7개입니다. 교육부 원본 5개와 SGIS·전체 공개 통합 검사는 별도로 실제 원본을 사용해 통과했습니다. 이후 수동 복구 명령과 공유 잠금 변경의 영향 검사는 별도로 구분해 독립 검증 기록에 남깁니다.

다음 핵심 작업은 최신 학교 통계와 영구 저장 가능한 공식 좌표, 정책·기관·다년 통계 연결입니다. 교육부 2020·2021 원문 경로 제한 조사 결과는 [과거 자료 기록](GANGWON_HISTORY_SOURCES.md)에 있습니다. 실제 지도 API와 운영 배포는 미검증입니다. [자료 요청 초안](GANGWON_DATA_REQUEST_DRAFT.md)은 작성만 했으며 기관에 발송하지 않았습니다.
