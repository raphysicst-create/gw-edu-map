SGIS 원본의 강원 시도코드는 `32`, 강원 시군구는 18개, 행정동은 193개다. 이것은 앱 내부 법정동 계열의 시도 `51`과 다른 체계다. 2026-06-30 국토부 CSV에서 강원특별자치도 `5100000000`과 읍면동·리가 빈 18개 시군 행을 확인했다. `data/manual/gangwon/region-crosswalk.json`은 SGIS 시군 5자리와 법정동 시군 10자리, 앱 내부 5자리 코드를 이름까지 대조하여 명시적으로 연결한다. SGIS 행정동 8자리는 그대로 보존한다. 인접 시도는 SGIS `31/33/37`을 내부 `41/43/47`에 대응시킨다.

`scripts/pipeline/gangwon/spatial.ts`는 등록된 ZIP SHA-256을 확인한 후 EPSG:5179 도형을 WGS84 경위도로 변환해 강원 시군구 18개, 인접 시도 3개, 행정동 193개를 반환한다. SGIS 원본의 `BASE_DATE`와 변환된 경위도 범위를 검사한다. 원본 ZIP 및 추출본은 `data/raw/gangwon/research-spatial/`에 보관하며, 앱의 공개 파일 쓰기는 별도 release gate가 담당한다.

## VWorld 배경지도·건물 자료

[국토교통부 2D 지도 API](https://www.data.go.kr/data/3052419/openapi.do)의 제공기관은 국토교통부, 공공데이터포털 표시 이용허락은 공공누리 1유형이며 인증키가 필요하다. [국토교통부 GIS건물통합정보 WMS/WFS](https://www.data.go.kr/data/15123970/openapi.do)의 포털 표시 이용허락은 제한 없음이나 개발단계 자동승인·운영단계 심의승인이다. 두 서비스 모두 VWorld API를 통해 이용하므로 포털의 데이터 라이선스 표시와 [VWorld 서비스 이용약관](https://www.vworld.kr/v4po_prcint_a001.do)을 함께 검토해야 한다.

조사 시점 VWorld 사이트가 보여 준 약관의 부칙은 2023-08-18 시행이다. 제13조는 인증키를 통한 웹 서비스 연동과 오픈플랫폼 표기를 허용·요구한다. 제19조는 서비스에서 얻은 정보의 복사·제공과 제공 데이터의 저장에 사전 승낙을 요구한다. 따라서 API로 얻은 학교 지오코딩 좌표를 영구 저장하거나, 건물 GeoJSON/지도 타일을 서버·CDN에 지속 캐시하거나 재배포하는 행위의 허용 근거는 확보되지 않았다. 포털의 공공누리·제한 없음 표기만으로 VWorld API 약관의 저장 제한이 해제된다고 판단하지 않는다. 사이트의 2026-08-18 공지 제목은 ‘브이월드 서비스 이용약관 개정 시행일정 연기 안내’로, 조사 시점 페이지의 표시 약관 외에 별도 시행된 개정 약관은 확인하지 못했다.

현재 앱의 외부 배경지도·건물 경로는 profile review 상수로 막고, 건물 API는 외부 호출 전 503과 `no-store`를 반환하도록 한다. 재개하려면 실제 사용할 인증키의 서비스 유형과 운영 승인, 저작권 표시, 저장·캐시의 서면 이용조건을 분리해 확인해야 한다. 국가데이터처의 독립 파일 경계 자료는 VWorld API 산출물이 아니므로 이 약관의 API 저장 제한을 적용하지 않는다.
