## 전체 회귀와 남은 제한

수동 롤백 테스트 추가 **전** `npm test -- --maxWorkers=2` 전체 실행은 71개 파일 중 70개 통과·1개 skip, 888개 테스트 중 881개 통과·7개 skip·실패 0으로 완료됐다(125.54초). 기본 검사는 ignored `data/raw/**` 없이도 수집·실행 가능하다. skip 7개는 교육부 XLSX 원본 5건, SGIS ZIP 변환 1건, 세 원본을 합치는 임시 공개 1건의 명시적 opt-in이다. 교육부 원본은 위의 5/5로, SGIS ZIP 변환과 변조 거부는 별도 2/2로, 교육부·SGIS·국토교통부 자료의 임시 공개는 별도 1/1로 통과했다. 합성 E2E 자료도 별도 검사자가 실제 `loadBundle → assertBundle → assertIssueData`로 검증했다(18시군·58학교·10주제·자원 251개).

Playwright 89건 전체 범위는 **82통과·7조건 skip·실패 0·미실행 0**으로 확인했다. CI 모드 프로덕션 빌드 검사와 동일 빌드의 로컬 프로덕션 서버를 이용해 파일 묶음별로 끝까지 실행하고, 수정한 실패 건만 다시 실행해 중복 없이 합산했다. 단일 `npm run e2e` 명령의 최종 완주 결과로 표현하지 않는다. 실제 2022 공개 자료는 준비/제한 화면 15건, 합성 자료는 학교점 선택·HUD·원통·키보드·URL history·교육문제 자원·WebGL 대체 화면을 검사한다. 합성 학교 좌표는 실제 공개 파일에 포함되지 않는다. 7개 skip은 기존 `LIVE_BUILDINGS=1` 필요 2건과 `DEPLOYMENT_URL` 필요 5건이다. 현재 VWorld 배경지도·건물 공개 gate가 꺼져 있어 일반 E2E는 미제공 안내와 외부 요청 0건을 검증하며, 실제 타일 표시·복구 동작은 검증하지 못한다. Linux CI와 배포 URL의 실제 실행도 이 로컬 검사 범위 밖이다.

E2E가 드러낸 제품 결함은 2022→2026 두 관측값 사이에 2025 자료가 없는데도 차이를 '전년 대비'로 표시하던 시계열 문구였다. 구현 담당이 직전 관측연도를 명시하도록 수정한 뒤 시계열 브라우저 3/3과 TimeSeriesChart·KpiTiles 컴포넌트 19/19가 통과했다. 나머지 첫 실패는 전북 숫자·학교명·메뉴 역할, 공개 gate, 새 원본 계약과 맞지 않던 테스트 fixture를 고쳐 해소했다. 기존 학교점/HUD·키보드·URL history 검사는 삭제하거나 단순 skip하지 않고 합성 강원 자료로 유지했다.

CI는 raw 원본을 다시 받지 않고 저장소의 `public/data/**`를 직접 검증한다. 기존 전북 평면 파일은 삭제 상태이며, 새 `public/data/releases/` 50개 파일과 manifest 및 현재 untracked인 `data/sources/gangwon/source-register.json`을 최종 변경에 포함해야 깨끗한 체크아웃에서 같은 결과를 얻는다.

## 최종 제한판 재현성 재검사

최종 `compile.ts`와 등록된 세 공식 원본을 그대로 사용해 Node.js 22에서 `npm run data:build`를 **순차 두 번** 실행했고 둘 다 종료 코드 0이었다. 두 빌드의 `dataVersion`은 모두 `gangwon-2022-563a6bb6162048a7`이었다. 첫 빌드와 둘째 빌드의 manifest 선언 경로 50개를 각각 파일 SHA-256으로 다시 읽어 비교한 결과 목록·해시가 모두 같았으며, `builtAt`만 제거한 manifest 내용도 같았다. `builtAt`은 각각 `2026-09-25T17:50:29.37Z`, `2026-09-25T17:52:14.437Z`로 예상대로 달랐다. 두 번째 빌드 직후 `npm run data:validate`와 `npm run data:gangwon:preflight`는 각각 종료 코드 0, `limited, 50개 공개 파일`을 보고했다. 이는 **최종 버전의 내용 재현성**에 대한 로컬 검사이며, 원본 재다운로드나 깨끗한 체크아웃의 Linux CI 결과는 아니다.

manifest의 50개 선언 파일은 제공 지표 13개 JSON, 해당 13개 시계열 JSON, 행정동 경계 18개, 학교·지역·인접지역·문자셋·교육문제·출처/결측 보고 6개로 구성된다. 보류 지표 5개의 개별 JSON과 보류 정책 주제 10개 각각의 파일, 폐교 별도 파일은 생성하지 않는다. 이들의 상태·사유는 manifest에 있고, 교육문제 공통 파일에는 공개 가능한 학교별 기초 사실이 있다.

별도 회귀 검사자가 임시 OS 작업공간에서 `npm.cmd test -- tests/pipeline/gangwon-rollback.test.ts tests/pipeline/gangwon-publish.test.ts --maxWorkers=2`를 실행해 신규 수동 복구 9건과 기존 자동 공개 5건, 합계 **14/14** 통과를 보고했다(2파일, 20.37초). `npm.cmd run typecheck`는 종료 코드 0, 신규 테스트 파일과 구현 파일 `rollback.ts`·`release.ts`의 lint도 오류·경고 0이었다. 검사 대상은 미리보기의 비변경, 정상 `limited` 복구와 선택 백업/교체 전 공개본 보존, SHA·다른 지역·`preparing`·출처 등록부 불허, 버전 경합과 동일 버전 거부, 빌드/롤백 공통 잠금, 경로 이탈과 백업/현재 공개본 junction 차단, 승격 rename 실패 시 기존 공개본 복원이다. 실제 `public/data`는 읽기만 했고 운영 호스팅이나 배포 URL의 롤백은 검사하지 않았다. 이 새 테스트와 롤백 구현을 반영한 전체 Vitest/브라우저 재실행 결과로 표현하지 않는다.

## 특수교육 정책 후보 등록 검사

교육청 공식 첨부 `gwe-2026-special-education-plan`을 `acquired` 후보로 등록한 뒤 실제 병합 `readGangwonRegister → assertSourceRegister`를 실행했다. 병합 출처 27건 중 후보가 한 번 포함됐고, 로컬 HWP 1,510,400바이트에 대한 `assertSourceBytes`가 등록된 SHA-256과 일치했다. 같은 후보 ID의 `assertPublishable`는 `공개 가능한 출처가 아닙니다`로 거부했다. 이어 Node.js 22의 `npm run data:validate`가 종료 코드 0, 기존 `limited, 50개 공개 파일`을 보고했다. 공개 빌드·전체 테스트·브라우저는 다시 실행하지 않았다. 이 확인은 파일별 공공누리 유형을 확정하거나 정책 주제를 공개로 승격한 결과가 아니다.
